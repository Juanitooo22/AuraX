EternionX
Modelo principal de AuraX con 12B parámetros. Excelente en español, conversación general y análisis de imágenes. Búsqueda web en tiempo real y verificación con IA. Ideal para preguntas de todo tipo.
KromaX
Modelo técnico de AuraX con 14B parámetros. Especializado en código: Python, JavaScript, HTML, SQL, MongoDB y más. Perfecto para desarrollo, debugging y matemáticas.
FineX
Modelo de razonamiento de AuraX. Piensa paso a paso antes de responder. Ideal para lógica, problemas complejos, matemáticas avanzadas y acertijos.

¿Qué puede hacer AuraX?

💬Responder preguntas en español e inglés sobre cualquier tema
🌐Buscar información actualizada en internet
💻Crear código en HTML, CSS, JavaScript, Python y más
🗄️Generar pipelines y queries de MongoDB
⚙️Diseñar flujos de automatización para n8n
🧮Resolver matemáticas y problemas lógicos

Cómo usar

🤖Cambia de modelo con el selector junto al título AuraX
🔍Activa o desactiva la búsqueda web con el ícono de lupa
✏️Renombra o elimina chats pasando el cursor sobre ellos
⌨️Enter para enviar · Shift+Enter para nueva línea
