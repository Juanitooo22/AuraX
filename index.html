EternionX
Modelo principal basado en Llama 3.2. Tiene búsqueda web en tiempo real con Google, Wikipedia y DuckDuckGo. Verificación con Claude Haiku para mayor precisión. Ideal para preguntas complejas, investigación y temas actuales.
Qwen 2.5
Modelo rápido y eficiente de Alibaba con 3B parámetros. Excelente para código, matemáticas, HTML, Python y respuestas generales. Corre 100% local sin internet. Ideal para tareas técnicas y creativas.

¿Qué puede hacer AuraX?

💬Responder preguntas en español e inglés sobre cualquier tema
🌐Buscar información actualizada en Google, Wikipedia y más
💻Crear código en HTML, CSS, JavaScript, Python, Lua y más
🗄️Generar pipelines y queries de MongoDB
⚙️Diseñar flujos de automatización para n8n
🧮Resolver matemáticas y problemas lógicos
📄Analizar documentos, imágenes y archivos adjuntos

Cómo usar

📎Adjunta imágenes, Excel, Word o PowerPoint con el ícono de clip
🔍Activa o desactiva la búsqueda web con el ícono de lupa
🤖Cambia entre EternionX y Qwen en el panel izquierdo
✏️Renombra o elimina chats pasando el cursor sobre ellos
⌨️Presiona Enter para enviar, Shift+Enter para nueva línea
